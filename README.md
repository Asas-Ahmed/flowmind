# FlowMind

FlowMind is an AI-powered productivity and personal management platform designed to help users improve focus, organize daily activities, and build productive habits through intelligent recommendations and analytics.

## Features

- User Authentication
- Task Management
- Habit Tracking
- Smart Scheduling
- Focus Sessions (Pomodoro)
- Productivity Dashboard
- AI Recommendations
- Analytics & Reports

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

### Database
- PostgreSQL

### AI & Analytics
- Pandas
- Scikit-learn
- Rule-based Recommendation Engine

## Architecture

FlowMind follows a **Modular Layered Architecture inspired by Clean Architecture principles**, separating the application into presentation, controller, service, repository, model, AI analytics, and database layers for better maintainability and scalability.
